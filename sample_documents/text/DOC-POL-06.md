# Remote Work, Hybrid Operations & Mobile Device Security Policy
Doc Code: DOC-POL-06 | Type: POLICY | Version: 2.0
Department: INFRA_IT | Organization: ApexNova Global Technologies

## Section 6.1: Remote Work Eligibility & Environment
Eligible remote employees must maintain a private workspace with secure high-speed internet and ergonomic seating.

## Section 6.2: Endpoint Disk Encryption Standards
All company-provided laptops must have BitLocker (Windows) or FileVault (macOS) full-disk encryption enabled and active prior to network authorization.

## Section 6.3: Public Network Connection Standards
When connecting through public Wi-Fi (airports, cafes, hotels), employees must route all network traffic through the company Zero Trust Network Access (ZTNA) tunnel.

## Section 6.4: Mobile Device Management (MDM) Mandate
Access to corporate email, Slack, or ticketing platforms on smartphones requires enrolling the device in Microsoft Intune MDM, permitting containerized corporate remote wipe upon separation or loss.
